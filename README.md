# PRTV TV A
Тестовое приложение показа слайд-шоу PRTV для Android TV.
Нативное, Kotlin, системный WebView. Без React Native, без Hermes,
без внешних зависимостей.
**Это исследовательский проект.** Он не заменяет действующее приложение
PRTV, не обновляет установленные копии и не предназначен для парка
клиентских устройств. Назначение — измеримое сравнение архитектур.
## Оформление
Главный экран повторяет раскладку приложения PRTV: тёмная колонка
настроек, фотопанель, три поля ввода с подсказками под цветные кнопки
пульта (зелёная — слайд-шоу, жёлтая — поток, красная — подборка).
Изображения `start_photo` и `prtv_logo_header` в репозитории лежат
заглушками — сеткой нужного размера. Настоящие файлы кладутся в
`app/src/main/res/drawable/` и перекрывают их: генератор пропускает
имена, для которых файл уже существует.
## Что умеет (этап 1)
- Показ слайд-шоу, подборки и потока по номеру
- Три хоста: `prtv.su`, `prtv.pro`, `new-test.prtv.su`
- Хост — параметр, а не список зашитых имён
- Последний код каждого типа сохраняется между запусками
- Постоянный идентификатор устройства, создаётся при первом запуске,
  наружу не передаётся
- Панель настроек: язык (русский, английский), выбор хоста, параметры
  кэша и режима сна — параметры сохраняются, сами механизмы появятся
  на следующих этапах
- Экран «Системные данные»: статус устройства, свободное место,
  версия WebView, журнал событий, вход в проверку слайд-шоу
- Кнопка MENU на пульте открывает системные данные поверх показа
## Чего пока нет
Этап 2 — watchdog показа, отдельный экран подборки.
Этап 3 — кэш медиа с лимитом и инвалидацией.
Этап 4 — офлайн-пакет и USB.
Этап 5 — автозапуск. Этап 6 — расписание через HDMI-CEC.
## Сборка
Локальный Android SDK не нужен: сборка идёт в GitHub Actions,
APK лежит в артефактах запуска.
Локально, если SDK есть:
```
python3 tools/make_assets.py
./gradlew assembleDebug
```
Иконки и баннер генерируются скриптом и в репозитории не хранятся.
Релизная подпись берётся из переменных окружения
(`PRTV_KEYSTORE_PATH`, `PRTV_KEYSTORE_PASSWORD`, `PRTV_KEY_ALIAS`,
`PRTV_KEY_PASSWORD`). Keystore в репозиторий не кладётся.
